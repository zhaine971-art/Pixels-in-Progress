# Pixels in Progress  
A personal developer blog documenting my journey from beginner to full‑stack developer.  
Built completely from scratch with HTML, CSS, and JavaScript and designed to grow into a full web platform as I learn more.

---

## About This Project
Pixels in Progress started as a simple static website where I could share my coding journey, projects, and thoughts as I learn to become a developer. Instead of using templates or frameworks, I chose to build everything by hand so I could understand every piece of what I’m creating.

The site will evolve over time as my skills grow. What begins as a static blog will eventually become a dynamic platform with user accounts, comments, newsletters, and more.

This repo is both my project and my progress tracker.

---

## Current Tech Stack
**Frontend**

## Future Plans (Roadmap)
This project is intentionally built to grow with me. Here’s what’s coming next:

### **Phase 1 — Static Blog (Complete / In Progress)**
- Build core pages (Home, About, Posts, Contact)
- Create reusable blog post template
- Add styling, banners, and layout polish

### **Phase 2 — Enhanced Frontend**
- Add animations and transitions  
- Add a search bar for posts  
- Add tags/categories for posts  

### **Phase 3 — Backend Integration**
- Add Supabase authentication (accounts, login, profiles)  
- Add comment system for blog posts  
- Add newsletter signup  
- Add admin dashboard for writing posts  
- Store posts in a database instead of static HTML  

### **Phase 4 — Full Platform**
- User profiles  
- Likes/upvotes on posts  
- API endpoints  
- Email notifications  
- Analytics dashboard  

This repo will evolve as I learn new technologies and build new features.
