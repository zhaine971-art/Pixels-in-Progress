100 Days of Python – My First Week of Progress

Posted on June 4, 2026

As I’ve mentioned in another post, I’ve been working through a Udemy course called 100 Days of Code: The Complete Python Pro Bootcamp. I’m currently on Day 6, and honestly, I’ve enjoyed the process way more than I expected.

I’m still very much a beginner, but I’ve already learned a ton from the courses I’ve taken so far. This 100‑day bootcamp is no exception. The instructor explains things clearly, shows how to use them, and makes everything feel approachable.

Day 1 focuses on variables and how to store data so you can reuse it later. Sure, you can hard‑code values everywhere, but the moment you need to change something, you’re stuck hunting through your entire script. Using variables saves you from that headache. Even in small scripts, it’s a good habit to rely on variables early.

Day 2 dives into data types and string manipulation. One of the first things you learn is the len() function, which returns the number of items in an object. For example, len("Hello") returns 5 because there are five characters in the string. But len() also works on lists and tuples. For instance, len([1, 2, 3, 4]) returns 4. 


import random

print("Welcome to the PyPassword Generator!")
nr_letters = int(input("How many letters would you like in your password?\n"))
nr_symbols = int(input(f"How many symbols would you like?\n"))
nr_numbers = int(input(f"How many numbers would you like?\n"))

password = ""

for letter in range(0, nr_letters):
password = password + random.choice(letters)

for symbol in range(0, nr_symbols):
password = password + random.choice(symbols)

for number in range(0, nr_numbers):
password = password + random.choice(numbers)

password_list = list(password)
random.shuffle(password_list)

shuffled_password = "".join(password_list)
print(shuffled_password)

You also learn how to print values to the console. Calling len("Hello") technically works, but you won’t see anything unless you print it. So you’d write print(len("Hello")) to actually view the result. There’s more covered in Day 2, but if I explained every detail from every day, this post would turn into a novel.

Day 3 covers control flow and logical operators. This is where Python starts feeling powerful. You learn how to make decisions in your code using if, elif, and else. You also get introduced to comparison operators like ==, !=, >, and <, along with logical operators such as and, or, and not. This is the day where your programs stop being straight lines and start reacting to different situations.

Day 4 jumps into randomization and Python lists. This was a fun one because you get to build small games and experiments using random.randint() and random.choice(). You also learn how lists work, how to create them, access items, modify them, and use them to store groups of data. It’s one of those days where everything suddenly feels more “real,” because you can start building programs that behave differently each time.

Day 5 focuses on loops, and this has probably been the hardest day for me so far. Loops are incredibly useful, but they can also be confusing when you’re new. You learn about for loops, while loops, and how to iterate through lists. It took me a bit to wrap my head around how loops control repetition, but once it clicked, I realized how much they simplify tasks that would otherwise take dozens of lines of code.

Overall, these first five days have been a solid mix of challenge and excitement. I’m learning that progress doesn’t come from being perfect. It comes from showing up, practicing, and letting yourself make mistakes along the way. I’m excited to keep pushing forward and see where the rest of this 100‑day journey takes me.

Now, if you look back at the code block above, you’ll see a password generator. This one really threw me off at first. I kept trying to piece it together, but nothing clicked. After watching the instructor break it down and then experimenting with it myself, it finally made sense.

The program starts with three lists: letters, numbers, and symbols. Each list holds a bunch of characters we can randomly choose from. Then the program asks the user how many letters, symbols, and numbers they want in their password. Those inputs get stored in nr_letters, nr_symbols, and nr_numbers.

The next step is combining the user’s input with the lists to actually build the password. This is where the for loops come in. For example, for letter in range(0, nr_letters): runs once for every letter the user requested. Inside that loop, we use password = password + random.choice(letters) (or the shorter += version). That line grabs a random character from the letters list and adds it to the password string. We repeat the same process for symbols and numbers.

At this point, the password works, but it isn’t fully randomized. It will always be structured like letters + symbols + numbers. For example: fea#$52.

To fix that, we shuffle the characters. The random.shuffle() function only works on lists, so we convert the password string into a list using password_list = list(password). Once it’s a list, we can shuffle it with random.shuffle(password_list). After that, we convert it back into a string using "".join(password_list) and print the final result. And of course, none of this works unless you import the random module at the very beginning.

Hopefully this explanation makes the logic behind the password generator easier to follow for anyone learning alongside me.
