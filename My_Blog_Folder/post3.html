100 Days of Python – My First Week of Progress

Posted on June 4, 2026

As I’ve mentioned in another post, I’ve been working through a Udemy course called 100 Days of Code: The Complete Python Pro Bootcamp. I’m currently on Day 6, and honestly, I’ve enjoyed the process way more than I expected.

I’m still very much a beginner, but I’ve already learned a ton from the courses I’ve taken so far. This 100‑day bootcamp is no exception. The instructor is one of the best I’ve listened to. She explains concepts clearly, shows how to use them, and makes everything feel approachable.

Day 1 focuses on variables which consists of how to store data so you can reuse it later. Sure, you can hard‑code values everywhere, but the moment you need to change something, you’re stuck hunting through your entire script. Using variables saves you from that nightmare. Even if a script is small, it’s a good habit to rely on variables early.

Day 2 dives into data types and string manipulation. One of the first things you learn is the len() function, which returns the number of items contained in an object. For example, len("Hello") returns 5 because there are five characters in the string. But len() also works on other data types like lists and tuples. For instance, len([1, 2, 3, 4]) would return 4 since there are four elements in that list.

You also learn how to print values to the console. Calling len("Hello") technically works, but you won’t see anything unless you print it. So you’d write print(len("Hello")) to actually view the result. There’s more covered in Day 2, but if I explained every detail from every day, this post would turn into a novel.

Day 3 covers control flow and logical operators. This is where Python starts feeling powerful. You learn how to make decisions in your code using if, elif, and else. You also get introduced to comparison operators like ==, !=, >, and <, along with logical operators such as and, or, and not. This is the day where your programs stop being linear and start reacting to different situations. 


import random

fruits = ["apple", "banana", "orange", "grape"]

print("Here are some fruits:")
for fruit in fruits:
    print("-", fruit)

random_fruit = random.choice(fruits)
print("\nYour random fruit is:", random_fruit)

Day 4 jumps into randomization and Python lists. This was a fun one because you get to build small games and experiments using random.randint() and random.choice(). You also learn how lists work, how to create them, access items, modify them, and use them to store groups of data. It’s one of those days where everything suddenly feels more “real,” because you can start building programs that behave differently each time.

Day 5 focuses on loops, and this has probably been the hardest day for me so far. Loops are incredibly useful, but they can also be confusing when you’re new. You learn about for loops, while loops, and how to iterate through lists. It took me a bit to wrap my head around how loops control repetition, but once it clicked, I realized how much they simplify tasks that would otherwise take dozens of lines of code.

Overall, these first five days have been a solid mix of challenge and excitement. I’m learning that progress doesn’t come from being perfect, it comes from showing up, practicing, and letting yourself make mistakes along the way. I’m excited to keep pushing forward and see where the rest of this 100‑day journey takes me.
